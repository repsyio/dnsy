01 · The pipeline

Every query takes
the same path.

Whatever the transport, each request runs through one pipeline. The first step that can answer ends it, and every request emits exactly one query event for the log and the stats.

Guard
ACL, per-client rate limit, sanity checks, no zone transfers
Decide
Blocklists, then your own zones, authoritative
Resolve
Cache, then upstream groups with a hard deadline; identical misses share one exchange
Trust
DNSSEC validation, scrubbing, response-IP policy
Shape
The client's id and flags back, AD and EDE added
02 · DNSSEC

Signs your zones.
Checks everyone else's.

DNSY validates the chain of trust from the root down for forwarded answers, and signs your own zones with keys it generates, stores encrypted and rolls over.

Validation
strict, permissive or off; negative trust anchors
Signing
ECDSA P-256 or Ed25519, NSEC or NSEC3
Lifecycle
automatic re-signing, KSK and ZSK rollover
Registrar
DS records ready to paste
03 · Private by default

Encrypted transports,
locked down.

Serve DNS over TLS and DNS over HTTPS next to plain DNS. Require client certificates on DoT, hand out scoped tokens for DoH, and forward upstream over TLS too.

DoT
mTLS off, optional or required, with an allowlist
DoH
token in a header or the path, HTTP/2
Upstream
forward over UDP, TCP or TLS
04 · Web panel

See every query.
Change anything.

A web panel built into the binary: dashboard, query log with live tail, zone editor with a DNSSEC tab, filtering, upstreams, users and tokens. Everything it does is also in the REST API.

Dashboard
queries, latency, cache hit ratio, blocked, DNSSEC outcomes
Query log
search, filter and tail live
REST API
OpenAPI 3.1, scoped tokens
